# Card Game War (python)

A console-based implementation of the classic card game war, written in python using Object-Oriented Programming.

---

## Features

- Classic WAR card game logic
- Player vs Computer
- Automatic handling of battles and wars (ties)
- Object-Oriented design
- Runs entirely in the terminal (no GUI)

---


---

## Game Rules

- A standard 52-card deck is shuffled
- Cards are divided evenly between the player and the computer
- Each round, both players draw one card
- The highest card wins the round
- If both cards have the same value, a **WAR** starts
- The game ends when one player has no cards left
